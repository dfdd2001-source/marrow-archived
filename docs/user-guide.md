# Marrow 使用手册

> 写给普通用户：不需要懂编程，照着做就能用。最后附有常见问题解答。

---

## 一、Marrow 是什么？

**Marrow 把教科书变成可以动手玩的数学。**

传统看书是这样的：读定义 → 读定理 → 看例题 → 自己做题（做错了也没人告诉你对不对）。

Marrow 是这样的：打开任意一节 → **拖动屏幕上的向量、拉动滑块** → 亲眼看到"内积什么时候为零""特征向量为什么不转向""行列式为什么代表面积"——然后做书里的每一道习题，勾掉已掌握的，随时查看经过机器验证的参考答案。

一句话：**它不替你读书，它让书里的抽象概念"动起来"。**

自带一个手写演示节（2×2 矩阵与线性变换，含可拖拽的网格变形探索）。用第七节的方法导入你自己的 PDF 书籍，即可获得同样的交互学习工具。

## 二、5 分钟上手

### 你需要准备什么

- 一台电脑（Mac 或装有 Python 的机器都可以）
- 没了。不需要安装数据库、不需要注册账号、不需要联网也能用。

### 方式一：只看不导入（推荐先用这个）

打开终端（Terminal），进入 Marrow 文件夹，输入：

```bash
./scripts/serve_app.sh
```

看到提示后，用浏览器打开 **http://127.0.0.1:8765/** 即可。这是"静态模式"：全部 26 节内容、探索动画、习题进度都可用，只是不能导入新书。

按 `Ctrl + C`（Mac 上是 `Command + .` 或 `Ctrl + C`）停止服务。

### 方式二：完整平台（可导入新书、多设备进度）

```bash
./scripts/serve_platform.sh
```

同样打开 http://127.0.0.1:8765/。这是"平台模式"：在静态模式基础上，多了**导入书籍**功能和**进度云端保存**（保存在你自己电脑的数据文件里）。它需要更多准备（见第七节），且启动后页面地址相同、用法完全一致。

> 两种模式可以随时切换，进度不会丢：静态模式进度存在浏览器里，平台模式会自动把浏览器进度合并到服务端。

## 三、认识界面

打开页面后，你会看到三个区域：

| 区域 | 在哪里 | 有什么 |
|---|---|---|
| **侧边栏** | 左侧 | 书籍列表（点击只看某本书）、目录 / **学习档案** / 导入书籍 / 设置四个入口、各书小节数量 |
| **顶栏** | 顶部 | 全局搜索框（搜术语、结论、例题、习题）、主题切换按钮 🌙 |
| **内容区** | 中间 | 首页显示"书籍 → 章 → 节"的卡片目录；点任意卡片进入该节 |

窄屏幕（如手机）上侧边栏会收起，点左上角 ☰ 按钮展开。

**全局搜索**：在顶栏输入任意词（如"正交"、"特征值"），会即时列出匹配的术语、结论、例题和习题，点击直接跳到对应小节。

## 四、打开一节：从上到下七块内容

以"6A 内积和范数"为例，页面从上到下依次是：

### 1. 知识结构图
一张自动生成的关系图，展示本节的定义和结论谁建立在谁之上（例如"柯西-施瓦茨不等式"建立在"正交分解"之上）。鼠标悬停在连线上可以看到"依赖关系"的文字说明。图下方有完整的关系列表。

### 2. 词典
本节出现的所有术语（如"内积""范数""正交"），每条带原书编号（如"定义 6.2"），方便你回原书对照。

### 3. 核心结论
本节所有可操作的定理/判据/构造规则，标"✓ 可执行"的表示这条结论精确到可以直接算。

### 4. 动手探索 ⭐（Marrow 的灵魂）
一块可以交互的数学动画区。玩法只有三种，一学就会：

- **拖圆点**：图上彩色圆点直接用鼠标拖，向量会跟着变；
- **拉滑杆**：下方的滑块控制矩阵元素、角度等参数；
- **看徽章**：图上的文字徽章实时显示当前数值，满足特殊条件时会**变色提醒**。

几个典型例子：

| 探索内容 | 你会看到什么 |
|---|---|
| 内积（6A） | 拖动 u、v 两个向量，当它们**垂直的瞬间**徽章亮绿色，提示"⟨u,v⟩ = 0 · 正交！" |
| 正交投影（6C） | 拖动 b 点，红色虚线（误差）实时变化；b 的投影点永远离 b 最近 |
| 格拉姆-施密特（6B） | 拖动 v₁、v₂，看 v₂ 怎样被"掰弯"成与 v₁ 垂直的方向 |
| 特征向量（5A） | 拉滑杆调整 λ，当上下两组条形**完全对齐**时出现"这就是一个特征向量！✓" |
| 矩阵变形（3A-3C） | 拖动滑杆改变矩阵，看网格被拉伸旋转、单位圆被压成椭圆 |
| 行列式（9B） | 拖动 u、v 组成平行四边形，绿色=逆时针、红色=顺时针，交换两向量面积变号 |

每块探索区下方都有一行灰色小字，告诉你这个图在演示什么、该怎么玩。

### 5. 例题（用于验证）
原书里直接给出解答的"例"，原书数值原样保留（标"原书数值"）。用途：对照检验你对结论的理解。

### 6. 动手练习（原书未给答案）
本节全部习题。每道题有三个动作：

1. **做题**：在文本框里写下你的答案或证明思路，点"提交作答"。
2. **看判分**：少数习题带"有机器验证答案"标签——这些答案由 AI 求解、其可计算声明经注册表机器重算，并经人工复核答案与声明一致。判对会显示绿色"✓ 与机器验证答案一致"。判分故意设计得很保守：只有能确认你答对了才打勾，确认不了就中性记录。所以"没打勾"不等于"你错了"，请展开参考答案自己对照；即使带标签的答案，也建议以推导过程为准。
3. **勾掉掌握**：右上角勾选框标记"已掌握"，顶部进度条随之前进。

> 诚实声明：目前大部分习题没有机器验证答案（证明题本来就无法自动判分）。带"有机器验证答案"标签的题可以放心对答案；其余题请与同学、老师讨论，或对照教材。

### 7. 相关内容
本节依赖的前置章节链接（如"6C 建立在 6A 的内积之上"），点击直接跳转复习。

## 五、学习进度与数据安全

- **进度存在哪？** 静态模式：只存在你浏览器的本地存储里，不上传任何服务器。平台模式：额外保存在你电脑的 `data/progress.json` 文件里。
- **换浏览器/换电脑？** 打开 设置 → **导出进度**，会下载一个 `marrow-progress.json` 文件；在另一台设备的浏览器控制台里恢复（高级用法），或直接在平台模式下使用。
- **想清零重来？** 设置 → **清除本地进度**。静态模式清掉浏览器里的进度；平台模式会同时清掉本机 `data/progress.json` 里的服务端记录，刷新后不会"复活"。

你的作答文本（平台模式）也只存在本地 `data/attempts.json`，**不会发送到任何第三方**。

---

### 进度导入与单节清零

- **导入进度**（设置 → 数据）：把之前导出的 `marrow-progress.json` 选进去，勾选记录会合并进当前设备（平台模式下同时推送到服务端）。导出 + 导入配对，换设备不用从零开始。
- **单节清零**：任意节的"动手练习"区有掌握记录后，计数旁会出现"清零本节"按钮，只清这一节。
- **搜索键盘流**：顶栏搜索框输入后，↑↓ 选择命中项、Enter 直达、Esc 关闭面板。

### 学习档案（📊）

侧边栏「学习档案」是跨 26 节的总览页：顶部是全部习题的总进度条，中间按章列出每节的掌握数（点击直达该节），底部是最近 20 条作答记录（时间、所在节、判分结果、你的作答摘要）。平台模式下它读你的账号数据；静态模式下读浏览器本地数据（作答历史仅平台模式记录）。

## 六、设置

点侧边栏"⚙ 设置"：

- **账号（多设备同步）**：填邮箱和密码（至少 6 位）点"注册并登录"。登录后，你的勾选进度和作答会按账号保存在本机服务端——换浏览器/换设备登录同一账号，进度自动双向合并；不想用了点"退出登录"（本地进度不受影响）。

- **主题**：浅色 / 深色 / 跟随系统（默认跟随系统，顶栏 🌙 按钮可一键循环切换）；
- **字号**：标准 / 大；
- **界面语言**：中文 / English。注意：**书籍内容语言跟随原书**（中文教材就是中文），这里切换的只是界面文字；
- **数据**：导出进度 / 清除进度。

## 七、导入一本自己的书（平台模式）

> 前提：使用 `./scripts/serve_platform.sh` 启动；电脑上装有 PDF 文本提取工具 `pdftotext`（`brew install poppler`）；项目根目录 `.env` 文件里有 AI 网关密钥（`AGNES_API_KEY`）。

步骤：

1. 侧边栏点 **📥 导入书籍**；
2. 填写 PDF 在你电脑上的完整路径（如 `/Users/你的名字/Desktop/某本书.pdf`）；
3. 点 **探测章节结构**，等 10-30 秒，会出现一张章节候选表格；
4. **人工勾选**真正的小节（探测是启发式的，会把目录页、页眉也列进来，需要你把关），必要时修正起止页码；
5. 给这批内容起个前缀名（如 `mybook`），点 **按勾选运行流水线**；
6. 每节约需 **3-6 分钟**（AI 会通读原文、提取知识结构、生成探索模型、核实忠实度），页面日志会实时显示进度；
7. 全部完成后回到首页，新书卡片就出现了。

**费用提示**：导入调用 AI 接口按 token 计费，导入整本书前建议先试 1-2 节看看效果和花费。

**质量保证**：导入的每一条内容都会经过两道关——① AI 对照原文核实忠实度，不忠实的内容直接丢弃；② "宁缺毋滥"原则：机器验证不通过的参考答案绝不出现在页面上。

## 八、安装到桌面/手机（PWA）与离线使用

Marrow 是一个 PWA（渐进式 Web 应用）：

- **Mac/Windows**：用 Chrome/Edge 打开页面 → 地址栏右侧"安装"图标 → 拥有一个独立窗口的桌面应用；
- **iPhone/Android**：浏览器菜单 → "添加到主屏幕"；
- **离线**：第一次打开后，页面框架和全部小节内容会被缓存，断网也能照常学习（导入功能除外，它需要联网调 AI）。

## 九、常见问题（FAQ）

**Q1：打开页面是空白 / "加载中"不动？**
服务没启动或端口不对。确认终端里服务在运行，且访问的是 `http://127.0.0.1:8765/`。

**Q2：端口 8765 被占用了？**
`./scripts/serve_platform.sh` 会自动清理占用；静态模式可以先 `lsof -ti :8765 | xargs kill` 再启动。

**Q3：首页看不到某本书的小节？**
侧边栏当前可能选中了"某一本"书，点回"全部书籍"即可。

**Q4：探索区的图不动 / 徽章一直显示"?"？**
参数被改到极端值导致计算无解（如矩阵奇异），把滑杆拉回中间即可。

**Q5：提交习题后显示"作答记录需要平台服务"？**
你正在用静态模式。作答判分和云端进度需要 `./scripts/serve_platform.sh`；静态模式下你仍可以勾选"已掌握"（存在浏览器里）。

**Q6：导入时提示"文件不存在"？**
检查路径是否为绝对路径、是否包含空格未加引号；PDF 必须在运行服务的那台电脑上。

**Q7：为什么搜索结果最多显示 12 条？**
当前版本为保持界面清爽做了截断，用更具体的关键词可以缩小范围。

## 十、已知限制（诚实清单）

1. **判分保守**：自由文本判分只对少数有机器验证答案的习题打勾，其余只做记录；
2. **章节探测有误报**：导入流程要求人工勾选确认，这一步省不得；
3. **探索可视化覆盖 8 类场景**；纯证明类题型以词典、结论、例题、习题呈现；
4. **导入内容的版权自负**：演示内容无版权限制；你导入的书籍内容是你的衍生品，公开分发前请确认对原书的权利；
5. **账号为本地设计**：账号与数据都在你自己电脑的服务上，没有云同步（跨设备指同一局域网内、登录同一账号的浏览器）。
